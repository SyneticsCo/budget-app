# AGENTS.md

## Project Description

This repository is a Python CLI budget app that manages household finance records using CSV files.

## Coding Rules

- Type hints are required for all functions and methods.
- Keep each function to a maximum of 20 lines.

## TDD Rules

- Always write tests before implementing production code.

## Quality Rules

- Keep cyclomatic complexity at 5 or lower.

## Test Commands

- Run tests with `pytest`.
- Check cyclomatic complexity with `radon cc`.
